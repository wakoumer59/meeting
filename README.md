# Gather Invitation

A polished static meeting invitation page built with HTML, CSS, and vanilla JavaScript.

## Run locally

```bash
npm start
```

Then open http://localhost:3000 in your browser.

## Deploy

This project is ready to be served as a static site. The included Node server can be used for local testing and production-friendly hosting environments that run Node.js.

### Production notes

- The app is a single-page static site.
- All assets are relative, so it can be deployed to any static host.
- The server script uses a safe path resolver to prevent directory traversal and serves the root `index.html` by default.
